# CompuMaster.CenterDevice.Rest 2026.10.20.0

- Removes the undocumented fixed allowance of 30 HTTP requests per minute from the default transport policy.
- Allows up to three active requests per HTTP origin, shared across synchronous, asynchronous, REST, authorization and download clients in one process.
- Adds `CenterDeviceHttpTransport.ConfigureRequestRateLimit(Uri, int?)` for explicitly enabling a known rolling-minute quota before the origin's first request. Passing null leaves the quota disabled; clients cannot bypass the allowance through a different URL path or username.
- Shares HTTP 429/503 cooldowns with queued and subsequent requests. Honors Retry-After seconds or HTTP dates and uses bounded backoff with jitter when the header is absent.
- Preserves bounded eligible read retries, cancellation, response/stream lease ownership, multipart ordering and no automatic replay of ambiguous writes.

Existing public signatures and synchronous APIs remain available. The admission defaults intentionally change; three concurrent requests are a client policy, not a verified manufacturer quota. Separate processes do not share these in-memory allowances.
